## Scores

- **Intelligence: 58/100** — Solid scaffolding (LLM provider abstraction, retry, prompt caching, parsing repair, validation framework, multi-provider catalog, IaC export). Severely weakened by single-shot JSON prompt strategy that violates ai-llm-eval rules (-27pp reasoning quality), a shallow per-framework compliance surface, post-hoc default injection that pretends to be intelligence, an architecture model that can’t express boundaries/intent/edge patterns, a benchmark that rewards what Cloudwright is good at, and a service-correctness number where Cloudwright is *worse* than raw Claude. Catalog already 3 months stale with no refresh job.
- **Feature Gaps: 45/100** — Big holes vs the competitor matrix Cloudwright already wrote: no Pulumi/CDK/Bicep/Crossplane export, no live import, no deploy/apply path, no drift integration, no team/collab/comment surfaces, no GitHub Action / VSCode / Backstage plugin, no PNG/SVG export, no animated/visual diff, no IoT/edge category, no right-sizing recommendations, MCP tools mirror CLI rather than agent intents. The Day-0 design story is real; Day-2 is empty.

## Three biggest unlocks

- **Two-stage prompting + boundary-aware spec.** Switch DESIGN to Stage 1 free-text architectural reasoning then Stage 2 JSON projection (recovers ~27pp), and promote `Boundary` (VPC/subnet/SG) plus `Connection.kind` (sync/async/stream/replication) into the prompt. Result: TF output stops being soup, compliance frameworks have something real to validate, and "service correctness" beats raw Claude instead of trailing it.
- **Pulumi + live-import + drift = a Day-2 product.** Ship Pulumi-TS + Pulumi-Py exporters (closest competitor is Pulumi Neo; same ArchSpec → their dialect), `cloudwright import-live --provider aws` walking boto3, and a continuous `cloudwright drift` that diffs ArchSpec vs deployed weekly. Closes Brainboard / Firefly / env0 gaps simultaneously.
- **Compliance you can hand to an auditor.** Replace the 5-7 check-per-framework surface with control-ID mapping (HIPAA §164.312, NIST 800-53, ISO 27001 Annex A, FedRAMP-Moderate baseline) and generate an auditor-ready PDF with evidence pointers and a shared-responsibility matrix. This is the regulated-industry differentiator that DuploCloud almost has and Cloudwright currently fakes.
