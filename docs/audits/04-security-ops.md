## Scores

- **Security: 58/100**
  Strong baseline (yaml.safe_load, Pydantic validation, regex-validated component IDs, path-traversal middleware, generic 500s on JSON routes, no eval/pickle/shell=True) is dragged down by a non-constant-time API-key comparison (#2), a SECURITY.md claim that doesn't match the IaC output (#3), unescaped HCL interpolation of `c.label`/`spec.region`/module metadata (#4), default-on Swagger UI (#5), exception-string leakage in SSE error frames (#7), and a Dockerfile that runs as root with no `.dockerignore` (#12, #22). The keys-in-`.env`-on-disk situation (#1) is gitignored so contained, but adds risk to any zip-based handoff.

- **Operational: 62/100**
  Real basics in place (Dependabot, SECURITY.md, structured logging, prod-shaped `serve()` worker count, lockstep version policy is documented in MEMORY.md). Held back by the four-package extras-pin brittleness with no CI guard (#10) — already broke once. Self-host story is incomplete: docker-compose is dev-shaped (#11), no healthcheck/volume/HSTS/runbook (#11, #15, #18). No Windows/macOS CI matrix (#13), no rollback runbook (#15), no `[mcp]` Dependabot config (#26), MCP `glama.json` drift not gated (#31), and the publish workflow has no approval step on tag-push (#14).

## Three Unlocks

1. **Make the IaC actually safe by default.** Add `aws_s3_bucket_public_access_block`, `server_side_encryption_configuration`, `versioning`, `aws_db_instance.storage_encrypted = true`, `metadata_options { http_tokens = "required" }`, and minimal-egress security groups to every renderer in `exporter/terraform/aws.py`. This single PR resolves findings #3 and #9, makes SECURITY.md honest, and turns the README's "safe defaults" claim from aspirational into demonstrable. Highest leverage on user trust.

2. **Lock down the multi-package release.** Add a CI guard that diffs `[project.optional-dependencies]` extras pins against `__version__` for all four packages and fails when they disagree. Switch extras from `==1.2.2` to `~=1.2.2` (compatible release) or `>=1.2.2,<1.3` so a CHANGELOG-only patch release no longer requires touching three other pyprojects. Closes finding #10 permanently and makes finding #14 (no approval gate) safer because the cost of a bad tag drops from "yank 4 wheels" to "yank 1".

3. **Ship a real self-host bundle.** Add `.dockerignore`, non-root `USER cloudwright`, `HEALTHCHECK`, digest-pinned base image, multi-arch build (`buildx`); add `docker-compose.prod.yml` with Caddy/Traefik front, persistent SessionStore volume, and a one-line "if you don't set `CLOUDWRIGHT_API_KEY`, the server refuses to start" banner. Resolves findings #5 (gate /docs in prod), #11, #12, #18, #22, #27 in one stroke and makes the "self-host vs SaaS narrative" credible for an enterprise prospect with VPC-routed LLM.
